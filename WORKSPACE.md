# GitHub store backup

This repository preserves the current ESPHomeBrew source, workflows, store generator, manifests, ports and tests in a self-contained layout. Its upstream history remains in Git; the PAX branch adapts names and accepts `pax/**` development pushes. Upload this folder to a new GitHub repository and configure Pages/release permissions there. Website output is generated by `.github/workflows/publish-store.yml`; no deployed website has been changed.

`backup-local.sh` saves Git bundles and a working-source archive under ignored `backups/`. It includes uncommitted source as well as history. It does not transmit anything. Actions are retained and renamed but must be exercised in the future GitHub repository before calling remote CI verified.
