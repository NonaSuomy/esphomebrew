PAXWEB LABReady

PAX in your browser

The real launcher and NetSurf sources, compiled to WebAssembly. Your browser keeps its own virtual SD card.

Click or tap the display. Arrow keys and Enter navigate; WASD and J/K act as gamepad directions and A/B. F1 is Start, Tab is Select, Escape exits. Only apps compiled for this web build can open.

Browser limits and logs

ESP32 RISC-V .pax binaries cannot execute in this source-compiled build. HTTP access follows browser CORS and HTTPS rules. No TCP/UDP server, hardware controls or firmware flashing is provided here. NetSurf retains the current port's JavaScript limitations.
