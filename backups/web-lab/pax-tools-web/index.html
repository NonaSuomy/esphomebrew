PAX in your browser

Run original RISC-V PAX apps or the source-built launcher and NetSurf. Your browser keeps its own virtual SD card.

Click or tap the display. Arrow keys and Enter navigate; WASD and J/K act as gamepad directions and A/B. F1 is Start, Tab is Select, Escape exits. The emulator runs original .pax apps; source mode runs the WebAssembly builds.

Browser limits and logs

RISC-V emulation supports ABI-1 PAX apps through browser services. App compatibility and performance vary. HTTP access follows browser CORS and HTTPS rules. No TCP/UDP server, hardware controls or firmware flashing is provided here. NetSurf retains the current port's JavaScript limitations.
