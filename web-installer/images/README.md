# Installer board photographs

## JC1060P470C_I_W_Y (black PCB)

`jc1060-c-i-w-y.jpg` is an unmodified rear-board photograph from the [JC1060P470C_I_W_Y hardware archive](https://github.com/wegi1/ESP32P4-JC1060P470C-I_W_Y/blob/56d01bd223c7db25b897a2da50bc3595be68c1c7/PICTURES/0a.jpg). It shows the black PCB, JC-ESP32P4-M3 module and RJ45 port. The model is also identified in Guition's [manufacturer specification](https://www.guition.com/hr/icms/upload/fb081940d6fc11f09850077a33e1404f/FTPData/UEditor/file/2026121/1768961093646/JC1060P470C_I_W_Y%20Specifications-EN.pdf), page 5.

Source SHA-256: `b63e310c29ea15dc17d23aae0191f1fd29ebd17464e2ed99e3c59dc02bf133d8`.

The previous `jc1060.jpg` shows the yellow PCB and is retained as a separate reference; it is no longer used by this black-board card. The photograph identifies the board assembly, not the LCD panel revision. V2-panel hardware needs its own firmware target.
