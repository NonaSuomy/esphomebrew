02 Connect and install

Select a device above to see its connection instructions.

Use a desktop browser with Web Serial support, such as Chrome or Edge.

Open this installer over HTTPS to connect by USB.

Download this board’s flash kit for offline installation

  1. Connect the board’s programming USB port with a data cable. Disconnect other flashing tools.
  2. Click Connect & install, then select the board’s serial port. If it does not connect, hold BOOT, tap RESET, release BOOT and retry.
  3. Install the selected firmware. Review the erase option before continuing; erasing clears saved settings.
  4. For Wi-Fi boards, enter your network details in the installer. For NANO, connect Ethernet to your router.

03 Add your apps

After network setup, use Visit device in the installer to open its SD setup page. Choose Install SD starter or upload files and folders over local Wi-Fi. Use a FAT32 or exFAT SD card. Extract the starter files to its root, so the launcher is at /roms/pax/launcher_ui.pax.

Insert the card, restart, then choose STORAGE. Use a USB keyboard or gamepad for navigation, or the touchscreen on supported panels.

Tab / arrows move between choices. Enter / Space selects. The starter includes the launcher and Recipe; game data is installed separately.
